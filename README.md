# Student Registration Ledger

A Student Registration System built with vanilla JavaScript, Bootstrap and DOM manipulation.

## Features
- Registration form (Full Name, Email, Phone, Course)
- Field-by-field validation with inline error messages
- Dynamic table of registered students with live record count
- Edit / update existing records in place
- Delete records instantly
- Empty-state handling and toast notifications on submit

## Tech Stack
HTML5 · Bootstrap 5 · JavaScript (DOM)

## Run Locally
```bash
git clone https://github.com/MuhammadBilalArshad102/StudentRegistrationForm.git
cd StudentRegistrationForm
```
Open `index.html` in your browser.
